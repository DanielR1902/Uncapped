PROJECT INTENT: UNCAPPED - AI-POWERED PC HARDWARE ENGINE

1. OVERVIEW & PHILOSOPHY
Uncapped is an AI-assisted, Spec-Driven Development (SDD) PC configuration platform built on Streamlit. The application streamlines custom computer assembly by eliminating compatibility guesswork, computing CPU/GPU bottleneck percentages, and optimizing component synergy against user constraints (budget boundaries, workload profiles, or open-ended free builds).

2. CORE WORKFLOW & AUTHENTICATION
- Landing Experience: Explanatory platform banner and three primary action triggers: [Create New PC], [View Previous Builds], and [Community].
- Auth Guarding: Main features remain locked until authentication. An inline modal/form provides seamless Login and Registration on the same page without navigation:
  * Register: Username, Password (hashed), Email, Full Name. Live duplicate validation flags conflicting username or email in red.
  * Login: Dual-identifier support (Username OR Email) plus Password.
  * Session State: Persistent login with an accessible Logout button in the bottom left sidebar.

3. PC BUILD ENGINE (THREE CREATION MODES)
Supports 8 core components (CPU, Motherboard, GPU, RAM, Storage, PSU, Case, Cooler) alongside optional peripheral expansion slots (Network Card, Sound Card, Optical Drive).
- Mode A: Budget Constrained Build
  * User defines a monetary ceiling.
  * Greedy/Max-coverage algorithm computes viable hardware patterns converging to the ceiling.
  * As parts are selected, viable remaining components filter dynamically to ensure final cost adheres strictly to the budget ceiling.
- Mode B: Workload/Need Profile Build
  * Filters hardware configurations tailored to specific profiles: General / Office, Gaming, Video Editing, Design/CAD, Programming/AI.
  * Pre-allocates tier-weighted component baselines matching workload needs.
- Mode C: Free Custom Build
  * Complete user freedom across all parts with real-time feedback and compatibility auditing.
- Dynamic Filtering & Synergy Sorting:
  * Hardware selection lists offer three live sorting criteria: Cost, Compatibility Score (%), and Value/Ratio Index (Cost vs. Compatibility Score).

4. COMPUTATION & EVALUATION ENGINE (HYBRID ARCHITECTURE)
- Deterministic Validation: Direct logic verifies hardware constraints (Socket compatibility between CPU and Motherboard, Total TDP vs. PSU Wattage headroom, Form factor dimensions).
- LLM Intelligence (OpenRouter): Computes real-time dynamic synergy score, bottleneck percentage, and architectural insights whenever parts change or builds are completed.

5. PERSISTENCE & USER BUILDS
- Storage: Dedicated storage tracking complete parts lists, total cost, bottleneck percentage, synergy score, timestamp, and user ID.
- Previous Builds View: Filterable dashboard supporting:
  * Workload profile category groupings (with nested chronological sorting).
  * Global sorting: Cost (High-to-Low), Cost (Low-to-High), and Date created.
  * Card UI rendering specifications, compatibility percentage, bottleneck rating, and quick actions to Clone, Edit, or Share to Community.

6. COMMUNITY COLLABORATION FORUM
- Public showcase where users publish finalized builds under custom post titles.
- Thread view presents complete specs, cost breakdown, performance analysis, and author notes.
- Interaction features:
  * User commentary and discussion threads.
  * "Fork / Customize" action: Loads post configuration directly into Create Mode for personalization.
  * "Save to My Builds": Imports the community build as an independent standalone entry in the user's private library.

7. DATA SCHEMA REQUIREMENTS
- Database: Structured storage (SQLite local / PostgreSQL cloud compatible).
  * Table 1 (Users): Credentials, profile metadata, creation timestamps.
  * Table 2 (Components): Full hardware catalogue across all categories with specifications (socket, TDP, price, form factor).
  * Table 3 (Workload Mappings): Relational mapping of components to intended workload profiles (General, Gaming, Editing, Design, Dev).
  * Table 4 (Builds): User configurations, component foreign keys, synergy score, bottleneck score, public status.
  * Table 5 (Community Posts & Comments): Forum entries, post content, metadata, and user replies.
